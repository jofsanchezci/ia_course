# Portal del curso de Inteligencia Artificial

Sitio estático creado únicamente con HTML, CSS y JavaScript.

## Actualizar el curso

Edite `script.js`:

- Cambie el estado de una sesión a `completed`, `current` o `upcoming`.
- Coloque presentaciones y talleres en `materiales/`.
- Agregue la ruta del archivo, por ejemplo `materiales/taller-01.pdf`.

## GitHub Pages

El flujo `.github/workflows/pages.yml` publica automáticamente cada cambio enviado a `main`.

Si es la primera publicación, abra **Settings → Pages** y seleccione **GitHub Actions** como fuente.
